## What This Is

The Sales OS is NoirFlow's complete playbook for turning strangers into paying clients — and paying clients into recurring revenue. It's built for Anshuman and Somyaranjan to run sales operations consistently, at any hour, from any city, with or without each other on the call.

## How to Use It

1. **Read all 11 docs end-to-end within your first week.**
2. **Re-read the ICP + Outreach Scripts before every outreach batch.**
3. **Have the Objection Handling doc open during every sales call.**
4. **Update docs after every real client conversation** — real data > our assumptions.
5. **Version-control this folder like code** — every change is a commit.

## Golden Rules of NoirFlow Sales

1. **Buyers before builds.** Never build for a niche without 3 real buyer conversations first.
2. **One founder = one deal.** Never both founders on the same lead.
3. **Every prospect goes into the pipeline (09) within 1 hour of first contact.**
4. **Never skip qualification.** A bad-fit client costs 40 hours to serve.
5. **Never quote price first.** Always ask their pain first.
6. **Care Plans are non-negotiable.** No care plan = walk away.
7. **Update the playbook after every deal — win or lose.**

## Weekly Sales Rhythm

- **Monday:** Review pipeline, plan the week
- **Mon–Fri:** 10 fresh DMs per founder per day = 100/week
- **Every day:** Follow-up sequence sends
- **Friday evening:** Weekly review — what worked, what didn't, update docs
