# Aurum Realty — Luxury Real Estate Portfolio Site

Demo portfolio site #3 for NoirFlow. A premium, single-file HTML website for a fictional luxury real estate consultancy in Bhubaneswar, showcasing the full-stack NoirFlow design system applied to the property sector.

## What's Inside

- **Nav** — Sticky, glass-blur on scroll, logo + WhatsApp CTA
- **Hero** — Full-screen cinematic background, trust badges, dual CTAs
- **Services** — 6 service cards with hover lift animations
- **Featured Properties** — 3 property cards with image zoom on hover
- **About / Founder** — Photo + bio + stats grid
- **Testimonials** — 3 cards on dark navy background
- **Contact** — Info panel + embedded Google Map
- **Footer** — Links + NoirFlow credit
- **Floating WA Button** — Premium navy/gold style (not standard green)

## Stack

Single-file HTML + Tailwind CSS CDN + Vanilla JS. No build step. Opens directly in any browser.

## Deploy on Vercel

1. Import this repo folder to Vercel
2. Set **Root Directory** to `portfolio/aurum-realty`
3. Framework: **Other** (static)
4. Deploy

## Customise for a Real Client

Replace in `index.html`:
- `919876588888` → client's WhatsApp number
- WhatsApp message text → client's preferred greeting
- Unsplash image URLs → actual property photos
- Owner name, bio, stats → real founder details
- Google Maps embed → actual office location
- Property names, prices, specs → real listings
